# Marketing — assets que ya armamos (lead magnets gratuitos)

## Lead magnets (ebooks gratis)
- **`guia-3-reglas.pdf`** — *"Por qué sigues perdiendo (y cómo dejar de hacerlo)"*.
  Lead magnet **comercial corto** (~6 págs, letra grande, pensado para LATAM / lector promedio).
  Objetivo: captar y convertir. Tono directo, sin jerga.
- **`como-se-construye-una-ventaja.pdf`** — *"Cómo se construye una ventaja"*.
  Versión **PRO / larga**: la **disciplina** (measure-first, el gate DSR) como diferenciador,
  **SIN revelar el algoritmo**. Para audiencia técnica / socios / lectores jodidos del humo.

Cada uno tiene su `.html` (fuente editable) y su `.pdf` (lo que se distribuye). Se renderiza
el PDF desde el HTML con Chromium headless.

## La regla (no negociable)
El pitch se **ata al registro validado**. Nada de R / win-rate que no salga del **ledger forward**
(`fq_motor.db`), nada del cementerio (cuántico, LPPL, etc.). El edge real que SÍ se puede contar:
order-flow (CVD), persistencia (F2), régimen (KL) — todos pasaron el gate. Ver `../ROLES/MARKETING.md`.
