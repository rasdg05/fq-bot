# Memoria de procesos — Marketing FQ

Snapshot of the FQ marketing/monetization work, mirrored here so it lives next to
the free-guide content it grew from.

**Origin:** built on branch `claude/marketing-video-editing-ijv4yv` under
`marketing/`. The docs below reference `marketing/...` paths that exist **on that
branch** (Remotion project, scripts, full carousels, landing app). This folder is
the durable record + the shippable artifacts.

## What's here
- `BRAND_VOICE_AND_STYLE.md` — communication tone (ES + EN), positioning, pillars,
  visual identity & curation, destinations, compliance.
- `PRODUCTION_NOTES_VIDEO.md` — video pipeline + audio quality bar (sync, ducked
  continuous music / no dead air, car-engine rescue, mastering, lip-sync note).
- `PROCESS_MEMORY_INDEX.md` — master index of every asset.
- `FQ-ebook-EN.pdf` — the new combined English ebook (rendered).
- `video/` — the 4 LIGHT English car-ad cuts (Telegram + landing, band + cover).
